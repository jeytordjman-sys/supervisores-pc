# Supervisores P&C

Aplicação de pilotagem das visitas às lojas — Perfumes & Companhia.

- **Protótipo interativo** (mobile-first, dados de exemplo, mapa OpenStreetMap, rota mais curta, agenda, ações): `index.html` — publicado em GitHub Pages.
- `src/artifact.html`: a mesma app no formato da página claude.ai (sem mapa externo).
- `docs/`: arquitetura e entregáveis, modo de emprego da sede (FR), guia rápido dos supervisores (PT), apresentação (PDF).
- `import-sage/`: script de importação noturna dos CSV do Sage X3 (stock, expedições, KPI) para a app real.

## Estado
Protótipo para teste pelos supervisores (1 ficheiro HTML, dados guardados só no browser). A app real (Floot) reutiliza a mesma lógica.
